# 🛒 STOCKMATE (SwipeStock)

> **1인 가구를 위한 틴더(Tinder) 방식의 생필품 재고 점검 & 24시간 열린 소비자포털 바코드 자동 등록 & 전몰 실시간 최저가 비교 쇼핑 애플리케이션**

---

## 📱 프로젝트 소개 및 핵심 기능

STOCKMATE는 반복적인 1인 가구의 생필품 재고 파악을 재미있고 직관적인 **Tinder 카드 스와이프 제스처**로 해결하고, **24시간 열린 소비자포털 (참가격 / KAN 표준유통DB)** 바코드 스캔을 통한 자동 등록, **쿠팡/네이버/11번가/SSG 등 동일 제품 실시간 최저가 비교 추천**, 그리고 **원클릭 결제 시 재고 자동 복구(+N 충전)**까지 지원하는 차세대 올인원 재고 관리 솔루션입니다.

---

## 🌟 5단계 핵심 서비스 흐름 & 탭 구성

### 1단계: [탭 1: 재고 목록 & 등록]
- **스마트 재고 보관함**: 보관 위치별(욕실, 주방, 펜트리, 세탁실) 및 카테고리별 실시간 필터링
- **24시간 열린 소비자포털 바코드 자동 스캔**: 생필품 바코드를 비추거나 입력하면 소비자포털에서 공식 상품명, 제조사, 권장소비자가격, 기본 비치 위치를 1초 만에 자동 완성
- **수동 등록 및 빠른 수량 조절**: `+`, `-` 버튼으로 원터치 수량 증감 및 편집 기능

### 2단계: [탭 2: 틴더 스와이프 체크 (SwipeStock)]
- **프로그레스 바 게이지**: 오늘 점검해야 할 재고 진행률(예: 1/10)을 시각적으로 안내
- **Tinder 인터랙티브 카드 덱**:
  - 🔴 **왼쪽 스와이프 / 왼쪽 버튼 ("다 씀 / 장바구니 담기")**: 재고를 0으로 처리하고 즉시 최저가 판매처 상품으로 스마트 장바구니에 담김
  - 🟢 **오른쪽 스와이프 / 오른쪽 버튼 ("넉넉함 / 패스")**: 재고 상태를 유지하고 다음 카드로 부드럽게 넘김
- **점검 완료 피드백**: 모든 항목 검사 시 부족 품목 요약과 함께 즉시 장바구니 결제 화면으로 이동 지원

### 3단계: [탭 3: 재고 상태 현황]
- **실시간 안전도 대시보드**: 우리집 생필품 안전 지수(%) 및 소진 위험도 분석
- **상태 태그 자동 분류**:
  - 수량 1개 이하: 🚨 **경고 (Warning, 붉은색)** 태그 및 `[추천 상품 보기]` 버튼 활성화
  - 수량 2개 이상: ✅ **여유 (Sufficient, 초록색)** 태그 표시
- **실시간 뱃지 연동**: 하단 내비게이션 바에 부족한 품목 개수 실시간 뱃지 노출

### 4단계: [탭 4: 제품 추천 & 실시간 최저가 비교]
- **동일 제품 최저가 비교 엔진**: 쿠팡 로켓배송에 국한되지 않고 네이버 쇼핑 스마트스토어, 11번가 슈팅배송, SSG 쓱배송, G마켓 등 동일 품목/동일 규격 가격을 한눈에 비교
- **🔥 최저가 보장 뱃지 & 단위가격(10m당/100ml당) 표기**
- **장바구니 담기 모달**: [장바구니 담기] 클릭 시 팝업 노출 ➔ `[장바구니 확인하기]` 클릭 시 Smart Cart 화면으로 즉시 전환

### 5단계: [탭 5: 스마트 장바구니 & 원클릭 결제 / 재고 자동 복구]
- **스마트 카트**: 선택한 판매처 최저가 상품 리스트, 수량 조절, 실시간 총 결제 금액
- **하단 Sticky CTA 버튼**: `총 OO,OOO원 한 번에 결제하기`
- **🎉 결제 완료 & 재고 자동 증가 (핵심 로직)**:
  - 구매 확정 시 해당 제품의 재고 수량이 자동으로 `+구매수량` 증가
  - 재고 상태가 `경고(Warning)`에서 `여유(Sufficient)`로 자동 복구 업데이트
  - 결제 내역(주문 히스토리) 탭에서 언제든 이전 구매 내역 및 충전 현황 확인 가능

## 🛠 기술 스택

- **Framework**: React Native (Expo SDK 51)
- **Navigation**: React Navigation (Bottom Tab Navigation)
- **Gesture & Animation**: PanResponder & Animated (Web/Mobile 완벽 호환 인터랙티브 덱 스와이프)
- **State Management**: React Context API (`StockContext` 전역 상태 및 실시간 뱃지)
- **Styling**: 모던 오프화이트 UI (`#F8F9FA`), 부드러운 다단계 섀도우(Soft, Card, Hover, Modal), 라운드 코너(Border Radius 16~28px)
- **Barcode & Open Data**: 24시간 열린 소비자포털 (참가격 / KAN 표준유통DB) 및 바코드 스캔 시뮬레이터

## 참가격 OpenAPI 연결 준비

- 상품 목록 API 프록시: `GET /api/products?q=상품명`
- 인증키는 서버에서만 읽습니다. `.env.example`을 `.env`로 복사하고 `KCA_SERVICE_KEY`에 공공데이터포털 발급키를 입력하세요.
- 인증키 발급: https://www.data.go.kr/data/15158701/openapi.do
- 결과는 서버 메모리에 6시간 캐시됩니다.
- 참가격 상품정보 API는 바코드 조회용이 아닙니다. 상품명과 참가격 상품 ID를 제공하므로, 기존 바코드 스캔으로 상품을 자동 매칭하려면 별도의 바코드 데이터가 필요합니다.
